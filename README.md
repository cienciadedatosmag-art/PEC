# PAEC

Comparación de precios en supermercados y tiendas de barrio en México.

## Descripción

Herramienta web que permite comparar precios de productos entre 
distintas tiendas (de barrio y cadenas de supermercados) para ayudar al usuario 
a encontrar las mejores opciones de compra.

## Tecnologías

- HTML / CSS / JavaScript (app de un solo archivo)
- Firebase Firestore (persistencia entre dispositivos)
- *(Prototipo inicial hecho en Plotly Dash)*

## Características

- Selección de productos mediante chips (sin barra de búsqueda)
- Comparación de precios entre tiendas
- Datos sincronizados en la nube con Firestore

## Instalación / Uso

\`\`\`bash
